## Direction

A personal engineer and researcher profile. The page begins with the real name, current role, concise biography, education/location, and Email / CV / Scholar / GitHub / Blog links. There is no system-architecture illustration, marketing headline, or hero CTA.

Projects are a readable list with employer, responsibilities, and concrete engineering work. The four entries come from the CV: Winmate / Samsung Proposal Studio; SRNote; on-device LLM training and evaluation; Hyundai private-cloud networking and automation. Hyundai's operations, routing migration, and Ansible work are grouped into one entry. Educational Agentic RAG and GraphRAG repositories are omitted.

Publication entries are text-focused, with year, venue, authors, description, and paper / official code / Scholar links. Experience, mentorship, and technical focus follow. There are no invented screenshots or profile photographs. The layout uses a narrow reading width, restrained blue links, small contextual labels, and clear section boundaries. Core profile and project content remains readable without JavaScript; project details, Korean translation, theme preferences, and citation copying enhance it.
